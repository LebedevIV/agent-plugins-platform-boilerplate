# Отладка коммуникации между SidePanel и Background

## Проблема
SidePanel получает `undefined` ответы от Background через 8ms, что указывает на проблему с асинхронной обработкой сообщений.

## Диагностика

### 1. Логи Background скрипта
В консоли браузера (F12) в разделе Extensions или Applications смотрите логи с префиксом `[background]`:
- `[background] Got message:` - входящее сообщение получено
- `[background] Processing message type:` - тип обрабатываемого сообщения
- `[background] processGetPlugins started` - начало асинхронной обработки
- `[background] Sending response data:` - отправка ответа
- `[background] Successfully sent plugins response` - ответ отправлен

### 2. Логи SidePanel
В консоли side-panel:
- `[SidePanel] Время отправки:` - время отправки сообщения
- `[SidePanel] Время получения ответа:` - время получения ответа
- `[SidePanel] Получен ответ от background:` - содержимое ответа

## Возможные причины проблемы

1. **Преждевременное закрытие канала**: `return true` возвращается слишком поздно
2. **Ошибка в sendResponse**: функция вызывается после закрытия канала
3. **Асинхронная обработка**: await блокирует выполнение дольше 8ms
4. **Исключения**: необработанные ошибки в асинхронном коде

## Исправления

### ✅ Применено:
1. **Ранний return true**: Возврат `true` происходит немедленно после получения сообщения
2. **Расширенное логирование**: Добавлены timestamp'ы и детальная диагностика
3. **Обработка ошибок**: Улучшена обработка исключений в асинхронном коде

### 🔍 Для проверки:
1. Проверьте логи на наличие ошибок sendResponse
2. Убедитесь, что `return true` происходит до запуска асинхронного кода
3. Проверьте, что sendResponse вызывается только один раз

## Тестирование

1. Откройте side-panel
2. Наблюдайте за логами в консоли
3. Проверьте, что ответы приходят не как `undefined`
4. Убедитесь, что время обработки не превышает 8ms для простых операций

## Следующие шаги

Если проблема сохраняется:
1. Проверьте логи на наличие исключений
2. Добавьте больше логирования в критические места
3. Рассмотрите использование Port API для более надежной коммуникации
4. Проверьте, нет ли конфликтов между разными обработчиками сообщений
