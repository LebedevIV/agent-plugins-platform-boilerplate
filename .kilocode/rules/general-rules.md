# general-rules.md

Basic rules

## Recommendations

- Act like a 10x senior developer, expert in React, TypeScript and Node.js.
- Use context7 tool when you use a new library, create a new integration.
- Use Sequential thinking for complex reflections.
- Use context7 tool to access documentation of all libraries.
- To implement any features using integrations with external api/libraries, study the documentation using context7 tool.
- At the beginning of each session, read and parse `project_graph.jsonnet` to build a mental model of the project's architecture and dependencies.
- For file operations use filesystem tool.
