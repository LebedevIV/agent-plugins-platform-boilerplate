# Каталоги-исключения для ProjectGraphAgent

## Обзор
Этот документ определяет каталоги, которые исключаются из аудита ProjectGraphAgent и не должны входить в контекст проекта при восстановлении в новом чате.

## Список исключенных каталогов

### 🔧 Служебные каталоги разработки
- **`node_modules/`** - Зависимости Node.js (автоматически генерируемые)
- **`dist/`** - Скомпилированные файлы сборки
- **`dist-zip/`** - Zip-архивы сборки

### 🤖 Каталоги AI-ассистентов
- **`.kilocode/`** - Конфигурация Roo Code
- **`.roocode/`** - Альтернативная конфигурация Roo Code
- **`.roo/`** - Конфигурация Roo Code
- **`.cursor/`** - Конфигурация Cursor AI
- **`.gemini/`** - Конфигурация Gemini Code Assistant

### 📦 Внешние ресурсы
- **`external/`** - Внешние проекты и boilerplate код
- **`backup/`** - Резервные копии файлов

## Причина исключения

Эти каталоги содержат:
- Автоматически генерируемые файлы (node_modules, dist)
- Конфигурацию IDE и AI-ассистентов (локальную для каждого разработчика)
- Внешний код, не являющийся частью основного проекта
- Временные и резервные файлы

## Настройка в ProjectGraphAgent

Исключения настроены в файле `ProjectGraphAgent/settings.json`:

```json
"audit_exclude_patterns": [
  "**/*.map",
  "**/*.log",
  "**/node_modules/**",
  "**/dist/**",
  "**/dist-zip/**",
  "**/.kilocode/**",
  "**/.roocode/**",
  "**/.roo/**",
  "**/.cursor/**",
  "**/.gemini/**",
  "**/external/**",
  "**/backup/**"
]
```

## Аудируемые директории

Следующие директории включаются в аудит и контекст проекта:
- `src/` - Основной исходный код
- `ui/` - Компоненты пользовательского интерфейса
- `docs/` - Документация
- `memory-bank/` - Система памяти проекта
- `platform-core/` - Ядро платформы
- `types/` - Определения типов
- `test-scripts/` - Скрипты тестирования

## Восстановление контекста

При восстановлении контекста проекта в новом чате:
1. Скопируйте основные директории проекта
2. НЕ копируйте исключенные каталоги
3. Запустите `ProjectGraphAgent/scripts/graph_generator.mjs` для восстановления графа
4. Контекст проекта будет восстановлен без служебных файлов
