## 🏗️ Архитектурный Контекст

Проект представляет собой **Chrome Extension** с архитектурой, включающей:

- **Frontend:** React 19+, TypeScript, Vite
- **Backend:** Python (Pyodide) для AI коммуникации
- **Мessaging:** MCP (Model Context Protocol) для связи JS ↔ Python
- **Storage:** IndexedDB + Chrome Storage API
- **UI Framework:** TailwindCSS + Radix UI
