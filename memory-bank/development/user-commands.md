## 📝 Документирование опыта

### Процесс документирования
1. **Найти решенную проблему** - проанализировать git log, issues, chat
2. **Извлечь паттерн решения** - определить общий подход
3. **Задокументировать** - добавить в соответствующие файлы:
   - `memory-bank/errors/` - конкретное решение
   - `memory-bank/development/` - best practices
   - `.cursor/rules/` - правила для AI

### Места для документации
- **Конкретные решения**: `memory-bank/errors/`
- **Best practices**: `memory-bank/development/`
- **AI правила**: `.cursor/rules/`
- **Кладбище ошибок**: `memory-bank/errors/error-graveyard.md`
